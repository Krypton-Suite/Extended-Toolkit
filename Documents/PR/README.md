# Pull request descriptions

This folder holds:

- `TEMPLATE.md` — shared skeleton for reviewer-facing PR bodies.
- Per-change files such as `NNNN-short-title.md` — **local working files**. Copy the template, fill it in, and pass it to `gh pr create --base alpha --body-file Documents/PR/<file>.md`.

Do **not** stage, commit, or push per-change description files as part of a pull request. Leave `TEMPLATE.md` and this `README.md` alone unless the task is to update those shared files.

See `AGENTS.md` → **Pull Request Descriptions**.
