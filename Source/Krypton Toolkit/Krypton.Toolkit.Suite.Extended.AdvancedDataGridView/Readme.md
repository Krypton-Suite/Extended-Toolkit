# Advanced Data Grid View

Excel-style filter and sort dropdowns on Krypton column headers (`▾` idle, `∇` filtered, `▲`/`▼` sorted, `★` saved filters). Bind a `BindingSource` and leave `FilterAndSortEnabled` at its default (`true`). The header menu checklist, search box, and Filter/Cancel buttons are Krypton-themed.
